# Design-partner maintainer checklist

Use with the canonical [`../DESIGN-PARTNER-PILOT.md`](../DESIGN-PARTNER-PILOT.md);
do not restate or change its thresholds here.

- [ ] Qualification and disqualification confirmed; profile recorded.
- [ ] User and potential economic buyer recorded separately.
- [ ] Exact artefact filename, version and SHA-256 recorded.
- [ ] Participant has Python 3.10–3.13 and a permitted public URL from their real workflow.
- [ ] CSV fields, permitted worksheet readers, consent/withdrawal, redaction,
      export, retention deadline and deletion choices agreed and recorded.
- [ ] Installation and intervention timers started/stopped; every intervention recorded.
- [ ] Initial baseline and scheduled repeated runs recorded.
- [ ] Support paused before the protocol's unprompted run.
- [ ] Alert/diff/provenance decisions captured before and after evidence where applicable.
- [ ] Integration request records destination, workflow owner and real decision process.
- [ ] Exit interview and continued-use/commercial-follow-through observations recorded.
- [ ] Participant chose deletion or retention; agreed action completed.
